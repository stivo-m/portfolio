Tech stack

Next.js is the right call, and not just because you already know it — using your own primary stack is a mini case study in itself. I'd go:

Next.js + TypeScript — App Router, static/SSG for the case study pages (fast, cheap to host, great SEO)
Tailwind CSS — you already use it professionally
MDX for case study content — write in Markdown, get React components when you need a diagram or interactive element inline
Vercel for hosting — zero-config with Next.js, free tier is enough
One small full-stack touch to prove you're not "just frontend" — e.g., a simple API route for the contact form, or (given your ML/Databricks background) a small AI-powered "ask about my experience" chat widget using the Claude API. That's a nice, on-brand differentiator since it's literally your risk-assessment/ETL skill set applied to your own portfolio.

Use apple-like design ideas, focusing on generous white space, clear white with subtle shadowns and no glass-effects. Clean typography and really professional design.
